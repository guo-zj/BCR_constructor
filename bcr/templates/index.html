BCR Constructor

Human antibody chain typing and membrane-bound BCR assembly, following antibody-chain-rules.md. Tables live in {{ data_dir }}.

1 Antibody library

Clean V domains in antibodies.csv. Tick the ones to assemble. Rows can be edited by hand — a hand-typed pair is held to the same typing and trimming rules as an imported one.

2 Assembly layout

Choose a preset to set the order of the assembled chain. Everything is pulled from the stored tables — no FASTA files are read at this step.

Select antibodies in card 1 first.

The whole chains each stored antibody implies, spliced with the intrinsic constant regions — IGKC / IGLC2 chosen from the antibody's own κ/λ call, and CHTMCTIgG1 or CHTMCTIgM for the isotype. Those four ship with the package and cannot be edited, so these columns are reproducible from the library alone. They are kept in antibodies.csv as well.

Express layouts — each places the whole light chain and the whole heavy chain of one isotype, so nothing but the signal peptides, linker and 2A elements comes from your parts table.

3 Build plan

Each antibody's light constant region is resolved from its own kappa/lambda call. Check it, then confirm to write the FASTA.

The file is replaced, not appended to.

4 Constructs library

Assembled constructs in constructs.csv, with the segment map each was built from. Tick rows to write them out again. A construct is assembled rather than typed in, so only its id and your notes are editable.

⚙ Utilities Sequence sanity check · Construct parts · Assembly presets ▲

Sequence sanity check

Types each sequence, checks it against its _VH / _VL header, and shows where it would be trimmed. Nothing is stored until you approve it.

⬇ Drop a .fa / .fasta file here or — a copy is kept in data/uploads/

Construct parts

Signal peptide, linker, and constant regions. Each is validated to begin at its own first residue. Stored as residues only — a trailing stop codon is dropped here and appended once at build time. A part already stored is compared against the incoming one before anything is replaced.

Four parts are intrinsic: they ship with the package, every layout resolves to them, and they cannot be edited, renamed or deleted. Their names are reserved — IGKC, IGLC2, CHTMCTIgG1, CHTMCTIgM — so a record in your file using one is offered a different name rather than overriding it.

⬇ Drop a .fa / .fasta file here or — a copy is kept in data/uploads/

Assembly presets

Drag components into the chain to set their order, N- to C-terminus. IGKC and IGLC2 share one tag, because a layout picks between them per antibody rather than naming one outright. Saved presets go to presets.json and become selectable in the Assembly layout card.
